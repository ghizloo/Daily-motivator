# Weekly Rhythm (Daily Motivator)

A gentle weekly planner, habit tracker and mood check-in that plans around the energy you actually have, instead of the energy you wish you had.

It is a single static file: `index.html`. Plain HTML, CSS and JavaScript, no build step, no dependencies. Everything is saved in your browser (localStorage) on the device you use.

## Run it

Open `index.html` in a browser. To host it, turn on GitHub Pages for the `main` branch.
